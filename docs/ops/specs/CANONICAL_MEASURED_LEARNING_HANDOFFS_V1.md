Subordinate composition of existing research and MI owners; no new system SSOT.
[Implementation and exact controlled scope](../evidence/durable_research_and_measured_mi_return_restoration_v1_2026_11_04/README.md).

## Native research session

measure_native_research_champion_v1 requires an explicit PROPOSED candidate,
resolved bars/config, matching Search robustness-policy fingerprint and explicit
comparison context. It measures4 engine paths and actually invokes Phase4 before
using its suite/metric versions. It preserves FAIL/BLOCKED; it does not promote.

NativeResearchExecutionArchiveV1 creates one content-addressed atomic packet with
exact numeric execution JSON, existing GVEF reference and measured receipt. Hash,
experiment identity, parameter/dataset domains and measured scores are bound on
read and append. Idempotent replay is permitted; divergence/path escape rejected.
No distributed transaction with Phase2/3/7 stores is claimed.

run_native_research_session_step_v1 requires the existing3 explicit memory stores,
a single-attempt Search budget and a native provider with the same identity and
retest context. It loads failures/gaps from their current durable owners before
Search. Explicit prior archive IDs supply actual persisted Meta inputs. Duplicate
prior IDs and conflicting memory lists fail closed. No PROPOSED candidate returns
NO_PROPOSED_CANDIDATE without measuring; it never manufactures a retest or loops
unboundedly. One successful attempt produces EXECUTED_AND_ARCHIVED. All times,
policies, data, observed gap values and evidence class remain explicit caller input.

## MI measured return calibration

calibrate_explicit_measured_return_v1 requires existing N_BARS observation,
measurement and evaluation information-set artifacts. Forecast provenance must
already contain measured_return_target_v1 with exact version, price basis,
LOG_RETURN, instrument/bar/N/horizon and first/last close times. The adapter does
not add this declaration to old forecasts or infer a label. Entity, ACTUAL mode,
knowledge-time and finite numeric return-distribution inputs are required.

The existing RETURN_ERROR_V1 owner consumes the original measured log_return;
no alternate outcome computation or economic-score mapping is created. Existing
MI triad persistence is reused. read_measured_return_calibration_v1 loads numeric
calibration_result under explicit durable/forecast/outcome IDs. No model training,
new direction thresholds, productive state write or broad quality certification.

Source authentication and natural effectiveness remain separate. Existing Source,
Scope, funding/accounting owners and original ledgers are preserved. No service,
network loader, order, automatic champion swap or productive authority.
