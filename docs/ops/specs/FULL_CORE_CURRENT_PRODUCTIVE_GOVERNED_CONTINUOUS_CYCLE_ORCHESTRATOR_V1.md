Derived spec. Non-SSOT. Canonical persist is Master Runbook
§11.2.1.EH S6 (historical compatibility label only).

`governed_continuous_cycle_orchestrator_v1`.

`OWNER_GO_EH_S6_GOVERNED_CONTINUOUS_CYCLE_ORCHESTRATOR_OFFLINE_BIND_V1`.

is not a runtime license. The continuous-run Owner-GO
`OWNER_GO_CURRENT_PRODUCTIVE_GOVERNED_CONTINUOUS_CYCLE_RUN_V1` is the
bounded continuous-run sequencing GO (`DEFINED_NOT_CONSUMED`). That GO
authorizes only bounded repeated instantiation of the existing S5
five-token cycle authorization. It does not substitute GET, EG,
occupancy, T2, or POST. It cannot mutate trading decisions and cannot
force ENTER. S5 remains the unchanged per-cycle primitive. POST remains
independently
`OWNER_GO_CURRENT_PRODUCTIVE_ACTUAL_VENUE_POST_WITH_FRESH_ENVELOPE_BOUND_SINGLE_USE_PERMIT_V1`
and cannot be composed, inferred, minted, or executed here. Direct V5
remains forbidden. Canonical policy does not set productive
`MAX_CYCLES_PER_RUN` / `MAX_RUN_DURATION`; validation-only fail-closed
defaults and hard caps apply. This persist does not execute the
continuous runtime. Offline tests require injected observation sources.
Network GET and `execute_network=true` remain unauthorized.
