# Full Core Residual Positive Necessary Kind Exhaustiveness Durable Unknown Pin V1

Derived spec. Non-SSOT. Canonical persist is Master Runbook §11.2.1.CI.
Consumes Owner-GO
`OWNER_GO_RESIDUAL_DURABLE_UNKNOWN_TO_NEXT_DEFINITIVE_BLOCK_V1`
with `SELECTED_PATH=PATH_B`. Satisfies the CH-named pin GO
`OWNER_GO_REQUIRED_TO_PIN_RESIDUAL_POSITIVE_NECESSARY_KIND_EXHAUSTIVENESS_DURABLE_UNKNOWN_PATH_B_AFTER_NONE_BINDABLE_V1`.

`DURABLE_UNKNOWN` is not `INCLUDE`, not `EXCLUDE`, not zero, and not
no-residual. It means
`POSITIVE_NECESSARY_KIND_INVENTORY_EXHAUSTIVENESS_CERTIFICATE_V1` is not
acquirable on current surfaces (`NONE_BINDABLE`, `GET_COUNT=0`) and
therefore remains fail-closed open. `NONE_BINDABLE` is provenance, not
absence. Further residual exhaustiveness acquisition is stopped. Path C
closeout is forbidden. Residual kind remains `REMAIN_UNKNOWN`. U05 and
U06 remain `REMAIN_UNKNOWN` / `DURABLE_UNKNOWN`. This GO does not
authorize a venue GET, a KIND_SET closeout, or a source mapping.

Existing fail-closed mapping and reconstruction contracts are consumed,
not rewritten. Reconstruction algebra remains incomplete on U04/U05/U06.
Residual is not an algebra term. Durable UNKNOWN does not complete the
algebra and does not create a canonically valid account-equity source
mapping.
