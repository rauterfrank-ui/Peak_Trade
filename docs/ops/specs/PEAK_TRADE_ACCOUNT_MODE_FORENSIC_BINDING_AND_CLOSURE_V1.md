This document is subordinate to the Master Runbook. Peak_Trade
`ACCOUNT_MODE` is the OKX account-configuration mode field `acctLv` from
authenticated `GET &#47;api&#47;v5&#47;account&#47;config`. Authority is
account-global. The only admissible Peak_Trade canary value is the exact
documented token `2` (Futures mode). Documented negatives are `1`
(Spot), `3` (Multi-currency margin), and `4` (Portfolio margin). Unknown
enums, empty, missing, null, and non-string types fail closed. `acctLv`
is not `posMode`, not `tdMode`, not `mgnMode`, not leverage, not
`settleCcy`, not instrument `state`, not available margin, and not
account identity. Account identity `uid` is a required metadata edge,
not the mode value.
