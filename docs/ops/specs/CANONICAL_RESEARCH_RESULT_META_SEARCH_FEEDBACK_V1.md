# Canonical research result Meta Search feedback v1

Subordinate to the Master Runbook. Research evidence only; productive authority NONE.

Owner: [existing-owner composition adapter](../../../src/experiments/canonical_research_result_to_meta_input_v1.py).

## Inputs and owners

Each `ResearchResultMetaInputV1` supplies an existing complete Search record,
Phase10 result and explicit time-horizon/market-universe values. Existing identity,
memory, robustness and comparison validators must admit their actual records.
Selected candidate, experiment/hypothesis identities, family/region/regime and
source times agree. Phase5 binds context values through its existing canonical
comparison API; no comparison digest is reinterpreted.

`build_meta_learning_from_research_results_v1` copies memory metrics and actual
robustness test statuses into the existing Phase11 unit type. Existing failure and
reality-gap records are consumed by the existing Meta owner. No metric formula,
threshold, missing stability, later outcome or regime is inferred. Duplicate
experiments and lookahead are rejected by the existing owners. Failed research
remains evidence input; overall Phase10 failure is not silently discarded.

`run_research_result_meta_search_feedback_v1` invokes that binding and existing
Meta/Search owners exactly once. The next Search request and explicit Meta policy
are caller inputs. Existing proposals/identity are forwarded without conversion
from M7 budget or opaque pattern text. Existing Meta input on the next request
must not be silently replaced. With no proposals, no Meta identity is injected
into Search; provenance remains in the enclosing result. Next Search chronology
must follow analysis. It produces candidate evidence, not an executed experiment.

## Witness and limitations

Source Search/loop/integrity, observation-binding and robustness/comparison
witnesses are retained with the actual Meta and next Search records. The envelope
has a content digest; historical experiment stores remain the owners. The Phase10
validator checks actual full integrity and existing loop identity, not just shape.
External authenticity, new-scope applicability and metric production remain
separate supplier contracts. Existing numeric sample/priority policies are reused.

No productive mutation, orders, promotion, risk increase, live/testnet activation,
service/scheduler installation or automatic experiment execution is authorized.
M6's original projection-only boundary is unchanged.

[Bound numerical control and checks](../evidence/numerical_research_meta_search_feedback_v1_2026_11_04/README.md).

## Metric semantics at an explicit supplier boundary

Field names, declared metric versions and valid identity digests alone do not
prove a producer's numeric units. A caller must establish the actual source's
frequency, annualization/risk-free convention, period, signs and units against
the receiving metric contract. This adapter does not infer or normalize those
properties from an opaque Sharpe or version field. Structural record admission
and numerical source applicability are distinct proofs. The controlled feedback
source now explicitly uses the target nonannual Sharpe convention; it is not a
general conversion adapter or natural experiment certification.
[Alignment and preserved earlier control](../evidence/numerical_feedback_nonannual_control_alignment_v1_2026_11_04/README.md).
