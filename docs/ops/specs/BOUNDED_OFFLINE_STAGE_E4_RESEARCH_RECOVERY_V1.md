## Before the provider

The existing public session API retains its explicit keyword arguments. A
nonblocking process lease at the original Experiment Memory root surrounds Search,
preflight, measurement and handoff. It coordinates callers using this session;
old standalone writers do not automatically participate in that lease.

The preflight reads validated original archive packets and exact stored owner
records. A matching complete original identity yields REUSE_ARCHIVED without
native measurement or a persisting Phase10 call. Its execution and Search remain
those of the original packet. Current source/config hashes, strategy/version and
instrument must still match for reuse; passing a second DataFrame or cfg does not
silently reinterpret an existing experiment. Missing/divergent owner records,
multiple original packets, incomplete standalone Memory, changed source/locator or
malformed retained content block new measurement. Explicit same-ID replication
returns REPLICATION_NOT_SUPPORTED_V1. New timestamps are not scientific identity.

An exact already-ACKed request replay is checked before current Failure/Gap state
can rerank Search. It returns the original trial rather than accidentally measuring
a second region. A deliberately new Search request can use the original Search
rules to choose another candidate, subject to identity preflight. Existing
NO_PROPOSED_CANDIDATE is the session's exhausted result; no trial is forced.

## Original prepared request and recovery

Before invoking a new provider, the session durably records a started handoff with
original Search, feedback, identity, request key and context digest. It lives in
`.research_steps_v1` under the existing Experiment Memory namespace. This is a
handoff journal, not a second authority for experiment/failure/gap results.

After the provider returns and the existing candidate/identity/time checks pass,
a new before-write hook validates the full original Phase10 request with store
handles removed. That pure validation runs the existing Phase10 calculations but
has no owner writes and never calls an engine. The exact native receipt is bound
to that result. The complete original dataclasses and numeric observations are
then persisted before Phase10 can append its first Memory record. A hook cannot
silently mutate the original request between validation and persistence.

The versioned JSON codec uses an explicit allowlist of existing dataclasses and
exact field sets, preserving original CreatedAt, hypothesis, scores, observations,
comparison, gap and policy. It uses no pickle or dynamic imports. Store handles
become typed canonical locators and must bind to the original supplied owner roots
on restore. Unknown types/schema, changed context, digest or archive locator block.
There is no implicit relocation, timestamp/seed replacement or record deletion.

An incomplete matching handoff is resumed before newly written partial Failure
records can cause Search to skip the very experiment needing completion. Recovery
uses only the retained request, receipt and original Search. Pure validation and
the existing idempotent persisting Phase10 loop run without a provider/engine.
Already present owner records must have identical content. A later archive error
retains earlier records and the prepared request. The existing exact numeric archive
is published/read back, every original Memory/Failure/Gap record is reread, and
only then is an immutable ACK written.

Interruption after measurement but before a complete prepared request is explicitly
uncertain. The started marker blocks a new trial; missing original data is never
fabricated. Process-death tests cover Experiment, Failure, Gap, Archive and ACK
writes and restore from fresh processes with the engine forbidden. This is not a
distributed commit or a power-loss/rollback certification. Standard owner writes
outside the cooperative session retain their original concurrency limits.

## Measured Meta effect and limits

The controlled acceptance study has three conditions, identical next-trial budget
one and explicitly preplanned seeds. Each historical trial is actually measured;
its original archive supplies full numeric Phase11 inputs. In the relevant
condition an explicit stricter OOS-collapse evaluation policy produces recurrent
Overfit findings for region fast_window=10/slow_window=50 from measured split
statistics. The existing Meta proposal changes the next Search priority; the
selected slow_window=100 candidate is then actually measured and persisted.
The baseline selects/measures 50. Applying the same strict study to the unrelated
75 region leaves the next choice 50 unchanged. Target Failure stores are empty
before feedback, so direct Failure filtering cannot explain that intervention.
Later Meta is computed from the exact reloaded next-trial archive numbers.

This is an explicit research-policy intervention using synthetic price data, not
a natural-market intervention, independent replications, universal market causality
or evidence of improved return. The strict study policy is not a productive default.
All missing robustness capabilities, unknown parameter stability/later outcomes,
pre-funding metric limits, synthetic gap context and lack of source authentication
remain explicit. No invented Shadow values, champion swap, training, productive
parameter application, Scope change or new operational authorization follows.

The durable witness also rereads next-trial metrics and passes the measured score
to the existing original Champion/Challenger numerical ranking owner, retaining
its full result. Its full-path Sharpe is 0.030562049388796947 for 50 and
0.030229745317592854 for 100; the latter is lower. Later Meta reload equality
proves retained input/analysis consistency, not that its missing later-outcome or
parameter-stability studies suddenly become computable. Those gates stay missing.
