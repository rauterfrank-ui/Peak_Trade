## 1. Dual authoritative inputs

Future Cap 2.2 economic ranking may consume exactly two authoritative
inputs with non-interchangeable roles:

```text
A) Cap-2.1 Governed Futures Universe Snapshot
   ROLE=STRUCTURAL_AND_SAFETY_ELIGIBILITY

B) Economic Market Input Snapshot
   ROLE=ECONOMIC_RANKING_FEATURE_INPUT
```

Cap 2.1 remains eligibility-only. It receives **no** ranking authority
and **no** economic-MD authority. Cap 2.2 remains the economic ranking
owner and must **not** become Public-MD Network SSOT or a live venue
session owner.

The Economic-MD-Input producer owns its own Public-MD network reads,
multi-instrument input collection, persistence, snapshot provenance, and
replay input. Cap 2.2 ranking consumes the persisted snapshot. Replay from
that persisted input is required. Direct live venue dependency inside Cap
2.2 remains `false`.

Current productive Cap 2.2 ranking is unchanged:

```text
CURRENT_PRODUCTIVE_RANKING_INPUT=CAP21_ONLY

```
