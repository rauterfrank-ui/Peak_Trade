## Closed-loop semantics

`CLOSED_MECHANICAL_LEARNING_LOOP=true` means: for an accepted real runtime path,
M4–M8 cycle output mechanically reaches validated M6 meta-learning evidence and
M7 bounded research feedback decision (authority=NONE, no learning_state mutation,
no search execution).

`CLOSED_PRODUCTIVE_OPTIMIZATION_LOOP=false` means: no candidate ratification,
productive configuration, runtime apply, or activation is implied or performed.

## Fail closed

Reject when G2→M4–M8 fails, DDO fixture is supplied, learning-evidence lineage
does not match the cycle, M6 ingest is incomplete, M7 feedback is missing or
revalidation diverges, or authority fields escalate beyond NONE.

## Non-implications

Feedback output produced ≠ runtime apply authorized ≠ strategy promoted ≠ live
activation.
