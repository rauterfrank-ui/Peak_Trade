```text
OWNER_RATIFICATION
!= INITIAL_STOCK_ACQUISITION_EVIDENCE
```

Target stock semantic is settlement-currency-native
`ABSOLUTE_SETTLEMENT_CURRENCY_ACCOUNT_EQUITY_FOR_OPTION_D_PRIOR`.
Acquisition evidence is GET `account&#47;config` plus GET `account&#47;balance`
`details[ccy == governed settlement_currency].eq`. Not `totalEq`,
`eqUsd`, `cashBal`, `availEq`, `adjEq`, PnL, or other currency rows.
`equity_unit` is `SETTLEMENT_CURRENCY_UNITS`. Currency code stays in
`settlement_currency`. `equity_precision` is derived lexical decimal
scale of the exact bound equity-value string. `as_of_time` is the
sealed balance `request_utc`. Venue `uTime` values remain raw metadata
and are not claimed equal to `request_utc`.

This GO does not ratify, does not mint an anchor, does not mutate
KIND_SET, and does not POST.
