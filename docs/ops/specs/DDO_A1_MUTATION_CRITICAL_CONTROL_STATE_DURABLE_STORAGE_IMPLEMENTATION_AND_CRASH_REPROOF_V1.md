OS-process SIGKILL after a successful commit, then reopen in a new
process, is process-restart evidence with bound POSIX-filesystem
assumptions. SIGKILL after prepare and before commit is process-crash
classification evidence. Neither is host-kernel crash. Neither is
power-loss. Normal CI may not set `HOST_CRASH_DURABILITY_PROVEN=true`,
`POWER_LOSS_DURABILITY_PROVEN=true`, `CRASH_DURABILITY_FULLY_PROVEN=true`,
or `DURABILITY_PROVEN=true`.
